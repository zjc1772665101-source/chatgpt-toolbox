# ChatGPT 长对话统一工具箱

一个面向 `chatgpt.com` 的 Tampermonkey 用户脚本，将长对话性能优化、双层导航、自适应大纲、提示词库、会话导出、字体排版和滚动修复整合在一个脚本中。

当前版本：**v1.6.73**。设置分类默认折叠，十处玻璃分别配置；支持 GPU 海洋与轨迹回放，并修复新版输入框灰条及顶栏横向背景。269 项经过校验的界面偏好构成默认预设。

## 安装

[点击安装最新版 userscript](https://raw.githubusercontent.com/zjc1772665101-source/chatgpt-unified-long-chat-toolkit/main/chatgpt-unified-long-chat-toolkit.user.js)

也可以下载仓库中的 `chatgpt-unified-long-chat-toolkit.user.js`，在 Tampermonkey 中新建脚本并粘贴完整内容。

安装后请停用功能重叠的旧脚本，避免重复目录、滚动钩子或提示词面板互相冲突。

## 功能

- 长对话性能优化：在兼容的旧版消息结构中，根据页面压力动态停放较早轮次，需要时可恢复。新版仅使用 `data-turn-key` 的布局尚未启用这个DOM回收模块。
- 问答导航：优先读取当前登录会话的完整分支目录，以消息 ID 对应已挂载的提问；纯附件提问也能定位。未挂载的历史目标会按会话位置逐步查找，API 不可用时回退到页面和原生目录。旧回答仍按需停放，不会为显示目录而常驻全部正文。
- 回答大纲：章节只来自当前回答，完整显示全部 H1-H6；语义标题较少时，结合回答开头、分隔线、真正位于段首的加粗标题和结构化段落自适应补足。18 项上限只约束自动派生项，不截断正式标题。
- 响应式浮窗：导航/提示词浮窗在瘦高窗口和手机视口中仍保持可见，并自动避开视口边缘、输入框和移动端安全区；支持浏览器顶层置顶，在页面遮罩、Popover 和原生弹窗上仍可交互。
- 提示词库：创建、编辑、删除、置顶、自由拖拽排序、搜索、分类、变量替换、快捷复制、加入发送队列和 JSON 导入/导出；管理与会话导出入口集中在搜索栏右侧菜单。
- 一键输入：点击提示词卡片主体，将内容写入当前可见的 ChatGPT 输入框，不自动发送；长提示词会避免重复触发模拟输入步骤。
- 发送队列：从输入框旁的队列入口批量排队消息，等待当前回复的正式正文、回复评价控件及稳定窗口后继续发送；思考摘要和临时停顿不会触发下一条。支持暂停、继续、移除、失败重试及每条消息的“立即发送”。手动发送可跳过队列顺序和自动稳定等待，暂停时也可发送；生成中会提示稍后重试，已有草稿、编辑或其他提交会阻止发送。
- Token 估算：可分别开关逐消息 Token 标签与本轮总览贴片；逐消息标签不显示在模型思考概览的活动摘要中。总览支持自动避让发送队列、位置预设与水平/垂直偏移，可在任意宽度强制使用 `输入/输出/上下文` 紧凑格式（如 `6/235/2.4k`），也可仅在窄屏自动紧凑；贴片文字、背景和边框颜色可独立覆盖，关闭覆盖后继续跟随 ChatGPT 明暗主题。复用会话导出的完整分支缓存，流式回答期间由当前 DOM 补齐最新输出。统计仅覆盖可见用户/助手文本，不包含系统指令、记忆、工具定义、隐藏推理等服务端上下文，因此只是近似值，不是官方 usage。
- 深浅主题适配：设置面板、导航浮窗、提示词、发送队列、Token 统计和公式复制提示默认跟随 ChatGPT 当前的浅色 / 深色主题，而不是只跟随操作系统主题；用户显式启用的自定义颜色仍具有更高优先级。
- 会话导出：Markdown、JSON、TXT 下载以及复制完整 Markdown；还可在正式回答结尾复制单条回答的 Markdown，保留可提取公式的 LaTeX 源码与定界符。支持新版智能UI粗体、表格公式、列表编号和含反引号的代码。DOM导出排除思考概览；导出不会保存按钮事件或可运行的富UI交互。
- 字体与排版：中文、拉丁、粗体、代码和数学排版设置，本地字体检测及 KaTeX/残余 LaTeX 修复；正文列左右边界、模型思考概览字号和公式字号可独立调整。新版智能UI正文、标题、粗体、列表、按钮、标签和滑块说明跟随字体字号；小按钮和标签高度随字号扩展。导航浮窗和发送队列也各有字体、字号、行高、面板宽度与配色设置。
- 输入区外观：移除新版输入区背后延伸到右侧滚动区域的全宽背景和渐变遮罩，保留圆角输入框及其控件。
- 滚动协同：生成期间阻止非用户触发的自动沉底，同时允许问答和章节导航正常跳转。
- 液态玻璃：输入框、导航／提示词、Aa 设置面板、发送队列、发送／语音／停止按钮、模型／麦克风工具胶囊、跳转箭头、Token 贴片、Aa 启动按钮和模型回答正文分别设置。各处具有独立开关、渲染模式、模糊、折射、色散与外观参数；主操作按钮保留原色调和原有事件。
- 渲染档位：可选完整 RGB 色散、单路折射或仅磨砂；新预设为经典风格与完整 RGB，可按面板选择更低负载。精致风格添加方向性薄边高光。按尺寸和参数缓存贴图，离屏及页面隐藏时暂停滤镜处理，回屏恢复。SVG 各阶段是否使用 GPU 由浏览器决定。
- 导航滚动条：问答、章节与提示词列表统一采用透明轨道、细灰色圆角滑块，隐藏上下箭头；仅作用于浮窗内部，不修改 ChatGPT 主页面滚动条。
- ASCII 鲨鱼海洋：8 种鲨鱼、独立配色与稳定随机配色；主页和对话页分别选择背景范围。可避开正文或为每条模型回答添加独立玻璃，用户消息保持原样。动画位于正文、输入框和工具贴片下方，避开左侧导航栏及滚动条。
- 回答玻璃：样式、折射、色散、模糊、圆角、底色等参数独立于其他玻璃；仅屏幕附近的回答持有滤镜资源，离屏时释放，滚回后恢复。
- 海洋性能：默认 12 帧，可调 3–30 帧；物理模拟、尾迹和画面刷新分开计时，降低帧率不会拖慢游动。缓存几何与重复计算，被遮挡区域跳过绘制；后台暂停，鼠标扰动可关闭。
- 海洋后端：标准 Canvas 2D、GPU 批量绘制、GPU 计算＋绘制可选；与实时模拟、15／30 分钟预计算回放自由组合。新预设为 GPU 计算＋绘制、30 分钟回放、节能画质、12 帧；实际后端与回退情况显示在设置中。回放仍需绘制并进行轨迹插值，不代表纯 GPU 或零 CPU。
- 逐项恢复：每个设置子项旁均有“恢复默认”。只恢复该项及其关联覆盖开关，配色模式同时恢复所属随机种子；不会重置其他项目或个人数据。269 个经过类型、范围和文本校验的偏好字段构成新版预设。
- 顶栏适配：可移除原生内容顶部预留和标题栏内部被拉宽的深色背景，保留项目标题、菜单与分享按钮；开关关闭可恢复原生布局。

## 使用说明

提示词变量写作 `{{变量名}}`。点击提示词卡片时会依次询问变量值，再把替换后的文本写入 ChatGPT 输入框。

自动队列不通过超时强制放行。如果回复评价控件被其他扩展隐藏，或者页面使用尚未识别的结束标志，队列会继续等待。“立即发送”只对选中的消息跳过自动等待，不会停止正在生成的回答，也不会覆盖输入框草稿；发送后其余自动消息仍等待新回复完成。

本版针对独立参数、工具胶囊、语音／停止按钮、附件与展开布局、异步贴图恢复和顶栏开关进行定向验证；269 项默认值与首次加载值逐项一致。真实 ChatGPT 页验证过针对原生背景层的临时样式修复。未将本地测试等同于完整安装后的所有真实账号流程验收。详见 [验证范围](VALIDATION.md)。升级时完整替换原同名脚本，不要同时启用两份。

玻璃设置位于 **Aa → 液态玻璃 · 各面板独立**。每次打开设置默认折叠全部分类。色散仅在完整模式使用；各面板可以复制输入框当前参数，之后分别保存。工具胶囊玻璃在新预设中默认关闭，可独立开启。

海洋设置位于 **Aa → ASCII 鲨鱼海洋（独立装饰）**；回答材质位于玻璃独立分组。海洋绘制方式与运动模式不控制玻璃。15／30 分钟影响循环长度及缓存大小，不改变画质；默认鱼群约占 26／52 MiB，数量和种类改变时占用也会改变。升级保留已保存设置；首次安装或恢复默认时使用新预设。

拖动整张提示词卡片可调整顺序；顺序会写入提示词本地数据，并随 JSON 导入/导出保留。卡片右侧两行图标依次提供置顶、编辑、复制原文和加入发送队列；桌面端悬停或键盘聚焦时显示，触摸设备上始终显示。分类显示在右下，删除入口位于编辑弹窗中。过长标题会自动省略，悬停标题可查看全文。

点击页面边缘的 `Aa` 按钮，在“导航 / 提示词浮窗外观”和“输入框旁发送队列外观”中分别设置界面样式；“回答复制 MD 图标颜色”也可单独启用。“模型的思考概览字号”位于“正文字号”下方。自定义颜色开关关闭时，两个界面继续跟随 ChatGPT 的明暗主题；在设置中修改导航贴片宽度也会更新此前手动保存的宽度。

从旧版本升级时，仅当正文颜色为历史白色／米白色组合且没有显式覆盖开关时，迁移才将其恢复为跟随主题；明确设置过的覆盖开关继续保留。

## 隐私与安全

- 不包含 API Key、访问令牌、Cookie、账号凭据、私钥、本机用户名或绝对用户目录。
- 不包含作者机器的完整字体清单；本地字体在浏览器中运行时检测。
- 新版默认配置只包含校验通过的界面偏好，不包含备份原文件、个人提示词、会话、发送队列或本地记录。
- 提示词和脚本设置保存在用户脚本管理器或浏览器本地存储中。
- 已补全的问答标题只缓存在当前浏览器标签页的 `sessionStorage` 中，关闭标签页后由浏览器清理。
- 会话导出在浏览器本地生成并下载，不会由本脚本上传到第三方服务。
- Token 估算同样在浏览器本地完成，不向第三方上传消息内容；完整活动分支读取复用脚本已有的 ChatGPT 会话接口与缓存。
- 脚本不包含遥测或统计上报。
- KaTeX 运行时和样式由 userscript 元数据中声明的 jsDelivr 地址加载。

## 兼容性

- 目标站点：`https://chatgpt.com/*`、`https://chat.openai.com/*`
- 推荐：最新版 Chromium 浏览器、Tampermonkey；移动浏览器需要支持 userscript 的脚本管理器
- ChatGPT 页面结构可能随时变化；若导航或输入功能失效，请附浏览器版本、脚本版本和截图提交 Issue。
