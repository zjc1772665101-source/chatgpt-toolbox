# Google AI Studio 工具箱 4.0.0

[安装脚本](https://raw.githubusercontent.com/zjc1772665101-source/chatgpt-toolbox/main/ai-studio-toolbox.user.js) · [模块化源码](../src/ai-studio/README.md)

适用 `https://aistudio.google.com/*` 和 `https://ai.dev/*`。已安装用户请在 Tampermonkey 中完整替换原 AI Studio 脚本并刷新；导入新条目时停用旧条目。沿用 v3 设置、提示词与队列存储键，刷新和恢复备份均不会自动发送。

## 拖动与设置入口

- 按住导航、设置或队列的标题栏，拖动整个窗口；独立入口可按住左侧握柄拖动。位置与尺寸会保存并在刷新后恢复。
- 拖动边缘或右下角缩放，双击标题栏最大化/恢复，折叠后仍保留标题栏。窗口尺寸变化时自动回到可见范围。
- 目录关闭后，独立的“设置”入口继续保留；`Alt + S` 打开设置，`Alt + Shift + R` 恢复所有位置。
- `Alt + G` 切换目录，`Alt + Q` 切换队列，`Esc` 关闭最上层窗口。聚焦标题栏后可用方向键移动，Shift 增大移动步长。

## 性能与恢复

消息索引和逐条缓存按变化失效；海洋绘制复用布局结果。页面隐藏时释放动画资源，减少动态效果时静态绘制。公式引擎与字体随脚本内置、按需初始化，修复分批进行。设置写入失败会提示；严格 Trusted Types、Worker 被 CSP 禁止或 GPU 不可用时保留相应回退。重复注入先卸载旧实例。

## 使用边界

- 导出默认处理已加载消息；历史收集只能尝试加载原站向浏览器提供的内容。隐藏思考不导出；对话中的附件记录名称或链接，完整队列备份则包含附件二进制。
- Token 是本地估算。字体取决于本机安装情况，内置公式字体除外；本地背景图片上限为 2 MiB。
- 队列需手动启动。草稿、原站附件、会话切换、回答状态不明确或超时会暂停；待确认项不自动重发。附件格式和模型能力取决于原站。
- 首次 15/30 分钟回放的完整预计算和完整时长播放未实测；已有短片生成、采样及 IndexedDB 往返验证。高密度动画、大量公式/历史和附件仍占用资源，可调低帧率、密度、范围和画质。
- 玻璃折射取决于浏览器支持，不支持时保留磨砂与底色。
