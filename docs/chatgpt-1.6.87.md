# ChatGPT 工具箱 v1.6.87

基于 v1.6.86 继续优化，包含前一轮针对上传 v1.6.85 的全部改进。将 `chatgpt-toolbox.user.js` 的完整内容替换进原来的用户脚本条目，保存后刷新 ChatGPT 页面。名称、命名空间、设置存储键、权限和依赖保持一致，原设置继续沿用。

仓库发布副本统一使用 LF 换行，除此之外与本地 v1.6.87 交付文件一致。下载校验以仓库根目录 `SHA256SUMS.txt` 为准。

## 改动

本轮新增：

- 公式解析改为直接查找 `$`、`\(`、`\[` 等候选定界符，普通正文不再逐字执行公式转义与起始符判断。
- 查找结束定界符改用原生字符串搜索，保留转义规则、行内换行边界、块公式、金额排除和表格数字公式的处理结果。
- Token 统计对现有消息内新增的正文片段直接使缓存失效，避免逐个搜索片段内的消息节点。新消息出现和离屏消息恢复仍执行必要的发现与缓存更新。
- 修复新结构的嵌套回答更新后，外层消息 Token 缓存可能未失效的问题。统计口径和估算算法保持一致。

前轮改进继续保留：

- 发送队列按消息复用未变化的行；内容不变时不再重建消息、附件图标和按钮。订阅回调直接使用已有快照，减少重复复制。
- 编辑队列消息时，普通刷新、新消息追加和其他行的更新保留原编辑框与光标；确实需要替换当前行时，恢复焦点、选区方向与编辑框滚动位置。
- 队列标题、按钮和状态仅在值变化时写入 DOM；空队列也复用提示节点，减少观察器被自身刷新唤醒。
- 公式和粗体修复在遍历时直接跳过代码、已渲染公式、编辑器和隐藏区域的整棵子树；复用排除选择器，保留原排除规则及处理顺序。
- 共享 DOM 观察器仅在实际监听范围改变时重新订阅；保留积压记录的投递与订阅者过滤规则。

## 保留的功能与效果

本轮完整差异验证确认：相对 v1.6.86，只改变 Token 缓存失效处理、公式定界符查找这三处函数及版本标记。海洋/GPU/轨迹回放、消息玻璃、玻璃样式与光学计算、目录、导出、Token 估算算法、提示词库、发送状态机和原有默认设置保持一致。未调整画质、帧率、鱼群密度、折射、模糊、色散或动画参数。
